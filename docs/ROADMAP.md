# Roadmap

## M2: Production-Quality Gladiator

Create one original high-quality modular gladiator. Generate separate body-part PNGs and pivot metadata; validate alignment in every pose and mirrored view. Replace procedural parts through the existing factories. Improve all seven required animations, weapon/shield shapes and hit feedback.

## M3: Gameplay Expansion

Add opponents, equipment and combat abilities; improve AI; extend arena progression and balance player growth against increasingly difficult encounters.

## M4: Content and Polish

Add bosses, audio, refined effects and expanded progression. Improve responsive interface behavior and establish browser deployment.

M1 deliberately excludes these later features.
