# Crossbow illustration

The Steel Crossbow is original procedural art in the Ash Vanguard palette. The stock and bolt rail run lengthwise; the bow limbs sit across the front of that rail. A separate string runs from the limb tips back to the catch. The short bolt sits on the rail, with its head projecting past the front. A trigger and guard sit below the rear grip; the front hand supports the fore-end. The front stirrup is a separate metal loop, not a rifle muzzle.

Visual reference: [Carl Olsen's crossbow silhouette, Game-icons](https://github.com/game-icons/icons/blob/master/carl-olsen/crossbow.svg). The reference was inspected for the transverse bow, string triangle, rail and stirrup silhouette; its SVG is not copied into the game. The game uses a separate three-quarter drawing with animated string and loaded bolt. Historical context: [Encyclopaedia Britannica, 11th ed., Archery](https://github.com/GITenberg/Encyclopaedia-Britannica-11th-Edition-Volume-2-Slice-4-Aram-Eugene--to--Arcueil-_34082/blob/master/34082-8.txt).

The item occupies both hands, fires one swept bolt per release and automatically reloads. Bolts are not inventory copies of the crossbow and cannot be collected as equipment. Throwing the crossbow itself with Ctrl+rear attack still uses normal thrown-equipment ownership and collection rules.
