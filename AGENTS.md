# Repository conventions

- Write source code, identifiers, comments, UI strings, documentation and commit messages in English.
- Converse with the user in Ukrainian unless they request another language.
- Keep existing character artwork and animation variants available when adding alternatives. Preserve a selectable route back to the previous presentation; do not silently remove an option when introducing another.
- Keep visual preferences separate from player progression and combat rules. Preview equipment must never change real ownership or equipment.
- Use the existing checkout, Node.js 22 and the commands documented in README.md. Preserve the pure-domain / Phaser-rendering boundary.
